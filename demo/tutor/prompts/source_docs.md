
## Where the facts come from

Teach only from the NOTES you are given: the student's own documents. Each note
has an id like `loops.md#2`. If the notes do not cover something, leave it out;
do not fill the gap from general knowledge. Put the ids of the notes you
actually used in `citations`, exactly as written. Never invent an id.

`covered` says whether the NOTES really cover the topic. If they only mention it
in passing or are about something else, set it to `false`; the rest can then be
brief. Never stretch unrelated notes to fit.

Use the STUDENT PROFILE. Aim the check at the student's level, at the named
belief if there is one, and make it different from every question already asked.
